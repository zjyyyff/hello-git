# 我的第一个仓库

这是我用 git 推送上去的第一个文件。

## 今天学会的命令

```powershell
git clone git@github.com:zjyyyff/hello-git.git   # 下载仓库
git status                                        # 看改了什么
git add .                                         # 暂存
git commit -m "说明"                              # 提交到本地
git push                                          # 上传到 GitHub
```
